# Cartoonizing Real Images

## About the Project
This project uses Python and computer vision to apply cartoon-style filters to real images and live camera frames.

## Features
- Real-time camera processing
- Multiple cartoon and artistic filters
- Switch between original and filtered views
- Save processed frames

## Technologies
- Python
- OpenCV
- NumPy

## Installation
Install the required libraries:

```bash
pip install opencv-python numpy
```

## How to Run
Open the project folder in VS Code and run:

```bash
python cartoon_camera_cv.py
```

Press `q` in the camera window to quit, `s` to save a frame, and `f` to switch filters.

## Purpose
This project demonstrates real-time image processing using computer vision.
